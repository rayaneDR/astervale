Know the way back.

This project currently provides source and an interactive browser prototype. There is no flashable AsterVale ROM download. A source ZIP cannot be installed on your phone.

Before any future build

Initial target: Samsung Galaxy A51 4G, SM-A515F, codename a51. The A51 5G and other model variants are outside the initial support scope. All AsterVale Android changes remain untested.

  1. Back up files, app data and authenticator recovery codes off the phone.
  2. Keep matching stock firmware with an equal or newer bootloader binary, and a private radio/EFS backup obtained through a trusted method.
  3. Confirm working Samsung Download Mode, USB drivers and a stock restoration route before changing partitions.
  4. Wait for an actual audited, checksummed candidate with model-specific recovery instructions.

Returning to stock

The A51 uses Samsung Download Mode. Generic fastboot flashing instructions do not apply. In a trusted Odin installation, matching stock BL, AP, CP and CSC files go into their corresponding fields. Clean CSC generally wipes data. Keep Re-Partition off; do not use random PIT files or downgrade bootloader binaries. Never relock with custom partitions.

Read the full recovery outline before testing. No Odin mirror or unverified binary is distributed here.

Building with no local AOSP host

AOSP documents 64 GB RAM and 400 GB free disk. Our recommended headroom is 700 GB SSD on Linux x86-64. This project's Windows 8 GB workstation cannot compile the ROM. Standard free GitHub runners can validate the source and website but do not have the disk space for a full ROM build.

With zero budget, full compilation depends on an existing suitable machine, a donated builder or a verified grant. None has been secured. No paid service is provisioned. See the build plan and primary-source cost comparison.
