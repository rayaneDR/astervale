# AsterVale
<!-- impeccable:product-schema 1 -->
## Platform
android
## Stack
Delegated explicitly by the owner: community LineageOS 23.2 / Android 16, A51 device trees, Standalone Java APK with Gradle 8.14.3 / AGP 8.13.2, plus separate future Soong/RRO layer. Buildless HTML/CSS/JavaScript browser prototype and GitHub Pages website.
## Users
Owner of an unlocked SM-A515F, 4–6 GB RAM, who will flash and test every candidate. Initial support excludes A51 5G and other A515 variants.
## Product Purpose
Extend the useful life of the A51 with a restrained, customizable system, understandable performance controls, and an optional permission-gated assistant.
## Constraints
Windows workstation: 8 GB RAM, no WSL2 or GPU; full-ROM compilation requires a proven free Linux host; no paid services. Standalone APK compilation uses existing Windows SDK and JDK 21. No device performance evidence exists. No Samsung proprietary binaries may enter this repository. Android feature architecture must support future Android 12+ device adapters; compatibility is not yet implemented across versions.
## Brand Commitments
Original identity, icons and wallpaper; iOS-inspired clarity and fluidity with Android back/navigation semantics. No Apple assets or fonts. AsterVale is a working name; preliminary search is not trademark clearance.
## Accessibility & Inclusion
48 dp targets, 200% text scaling, reduced motion, light/dark themes, contrast checks, logical layout, RTL and Arabic.
## Evidence
Public upstream files inspected on 2026-11-10. Browser captures are prototype evidence only. No bootable AsterVale image or owner test result exists.
